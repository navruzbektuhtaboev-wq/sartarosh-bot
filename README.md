# Сартарошхона учун Telegram ёзилиш боти

Мижоз Telegram орқали сартарошни, хизматни, кун ва бўш вақтни танлайди ва ёзилади.

## Нима қила олади

- ✂️ **Ёзилиш**: сартарош → кун → бўш вақт → телефон → тасдиқлаш (агар `services` да бир нечта хизмат бўлса, хизмат танлаш ҳам чиқади; `price` берилса нарх кўринади)
- Банд вақтлар кўрсатилмайди, хизмат узунлиги ҳисобга олинади (масалан, 60 дақиқалик хизмат)
- Икки мижоз бир вақтни бир пайтда танласа, фақат биттаси ёзилади
- 📋 **Ёзилишларим**: мижоз вақтни ўзгартириши ёки бекор қилиши мумкин
- ⏰ **Эслатма**: вақтидан 2 соат олдин (созланади)
- 🔔 Янги ёзилиш / бекор қилиш ҳақида админ ва сартарошнинг ўзига хабар
- Ходимлар учун буйруқлар: `/bugun`, `/ertaga` — кунлик рўйхат; `/myid` — Telegram ID ни билиш
- 📅 **Google Calendar** (ихтиёрий): ҳар бир ёзилиш сартарошнинг календарига тушади, сартарош календарга ўзи қўйган бандлик (тушлик, дам олиш) ботда банд бўлиб кўринади

## Windows компьютерда ишга тушириш (энг осон йўл)

1. https://www.python.org/downloads/ дан Python'ни ўрнатинг. Ўрнатишда **«Add python.exe to PATH»** белгисини қўйинг.
2. ZIP файлни очинг (ўнг тугма → «Извлечь все» / «Extract All»).
3. Папка ичидаги **start.bat** ни икки марта босинг. Биринчи марта токенни сўрайди: BotFather берган токенни қўйиб Enter босинг.
4. Қора ойнада «Bot ishlayapti» чиқса, бот ишлаяпти. Ойнани ёпманг (кичрайтириб қўйса бўлади).
5. Telegram'да ботингизга `/admin` деб ёзинг: сиз админ бўласиз ва ҳар бир ёзилиш ҳақида хабар оласиз.
6. Компьютер қайта ёқилганда бот ўзи ишга тушиши учун: `Win + R` → `shell:startup` → очилган папкага start.bat нинг ярлигини (shortcut) ташланг.

## Сервер/Linux да ишга тушириш

1. Telegram'да [@BotFather](https://t.me/BotFather) га `/newbot` ёзинг ва токен олинг.
2. `config.example.json` ни `config.json` қилиб нусхаланг ва тўлдиринг:
   - `barbers` — 4 сартарош исми; `telegram_id` — сартарошга хабар бориши учун (сартарош ботга `/myid` ёзиб билади)
   - `services` — хизмат, нарх (сўмда), давомийлик (дақиқа)
   - `work_start`, `work_end` — иш вақти; `days_off` — дам олиш кунлари (0 = душанба, 6 = якшанба)
   - `admin_ids` — сизнинг Telegram ID (барча ёзилишлар ҳақида хабар оласиз)
3. Ишга туширинг:

```bash
pip install -r requirements.txt
BOT_TOKEN=123456:ABC... python -m bot.main
```

Docker билан:

```bash
mkdir data && cp config.json data/
docker build -t barber-bot .
docker run -d --restart=always -e BOT_TOKEN=123456:ABC... -v $PWD/data:/data barber-bot
```

Бот доим ишлаши учун уни сервер/VPS да (ёки Railway, Render каби хизматда) ишга туширинг. Ёзилишлар `bookings.db` файлида сақланади.

## Google Calendar улаш (ихтиёрий)

1. [Google Cloud Console](https://console.cloud.google.com/) да лойиҳа очинг, **Google Calendar API** ни ёқинг.
2. **Service account** яратинг, JSON калитини юклаб олинг → `google-credentials.json`.
3. Ҳар бир сартарош Google Calendar'ида: Созламалар → «Бошқалар билан бўлишиш» → service account email'ини қўшинг, рухсат: **«Тадбирларга ўзгартириш киритиш»**.
4. `config.json` да: `"google_credentials_file": "google-credentials.json"` ва ҳар сартарошга `"calendar_id"` (одатда унинг Gmail манзили).

Календар уланмаса ҳам бот тўлиқ ишлайди.
